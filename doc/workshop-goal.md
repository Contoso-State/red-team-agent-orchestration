# End-to-end workshop goal

Make Red Team Orchestration explain and demonstrate graph engineering, real
Azure agent coordination, evidence-backed memory reuse and bounded target code
evolution. Work on `codex/demo-security-subscription`. Keep aef-core read-only,
and keep demo scope, inventories, findings, logs, memory and screenshots in
ignored engagement directories; never upload them to the primary branch.

1. Verify the canonical graph, native agent definitions, read-only guardrails,
   scoped inventory preflight and datastore provenance. Preserve existing work.
2. Consume the verified latest compatible AEF source as a pinned target-local
   wheel. Wire real Services, retrieval/consolidation/reflection, bounded agent
   context, checkpoints and source IDs. Report unavailable upstream features.
3. Make both 3D graphs understandable: resource relationships in the report;
   agent execution, actual transfers and moving packets in the observatory.
   Show real timelines, per-run selection, memory stages and inspectable source
   references. Label history replay and coverage gaps accurately.
4. Enable a finite target-only code loop with a fixed mutation surface,
   preserved regression contract, incumbent/candidate/null comparisons, atomic
   application and an audit trail. Keep guardrails, evaluators and AEF source
   outside its write boundary. Reject unchanged or regressing candidates.
5. Run relevant automated tests and desktop/mobile browser checks. Verify real
   SSE updates, packet motion, run filters, timestamps, provenance and layout.
6. Within the explicitly authorized demo scope, run fresh read-only assessments
   with preflight and compare distinct sessions. Stop dependent execution at any
   tool-enforced security block; do not route around it. Local reviews may proceed.
7. Demonstrate verified reuse and distinct-run corroboration. Claim improved
   security outcomes only after matched evaluations measure them. Memory context,
   code routing improvements and model retraining are different outcomes.
8. Deliver a workshop runbook, executed-test evidence and an honest readiness
   report. Do not declare the whole workshop green while live validation,
   coverage or measured learning outcomes remain missing.
