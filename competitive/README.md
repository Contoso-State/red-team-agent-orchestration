# Competitive Intelligence

Battle cards and competitive positioning against key security vendors.

## Structure
- `battle-cards/` — Per-competitor analysis (e.g., `crowdstrike.md`, `splunk.md`, `palo-alto.md`)

## Battle Card Template
Each card should cover:
1. **Vendor overview** — What they sell, market position
2. **Head-to-head** — Feature comparison matrix
3. **Our strengths** — Where Microsoft wins
4. **Their strengths** — Where they differentiate (be honest)
5. **Objection handling** — Common pushback and responses
6. **Trap-setting questions** — Discovery questions that highlight their gaps
7. **Customer proof points** — References and case studies
