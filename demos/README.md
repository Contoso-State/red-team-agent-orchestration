# Demo Library

Reusable demo assets organized by Microsoft Security product. These are product-level demos — customize copies in account folders for specific customers.

## Products

| Folder | Product | Key Scenarios |
|--------|---------|---------------|
| `defender-xdr/` | Microsoft Defender XDR | Incident investigation, automated response, cross-workload detection |
| `sentinel/` | Microsoft Sentinel | SIEM migration, KQL hunting, SOAR playbooks, analytics rules |
| `entra/` | Microsoft Entra ID | Conditional Access, PIM, identity governance, SSO |
| `purview/` | Microsoft Purview | DLP, sensitivity labels, insider risk, data classification |
| `intune/` | Microsoft Intune | Device compliance, app protection, Zero Trust endpoints |
| `copilot-security/` | Security Copilot | Incident summarization, script analysis, threat intel |

## Demo Naming Convention
`<scenario-name>.md` — e.g., `siem-migration-playbook.md`
