# Security Scenarios & Playbooks

Common security scenarios mapped to Microsoft Security solutions. Use these as starting points for customer engagements.

## Categories

| Folder | Focus Area | Examples |
|--------|-----------|----------|
| `threat-protection/` | XDR, EDR, email security | Ransomware response, phishing investigation, lateral movement detection |
| `identity/` | Zero Trust identity | Conditional Access rollout, PIM adoption, identity governance |
| `cloud-security/` | CSPM, CWPP, multicloud | Defender for Cloud posture, multicloud visibility, container security |
| `data-security/` | DLP, classification | Sensitive data discovery, DLP policies, insider risk |
| `siem-soar/` | SIEM & automation | Splunk-to-Sentinel migration, SOAR playbooks, cost optimization |
| `compliance/` | Regulatory | NIST, CIS, SOC2, HIPAA, GDPR compliance mapping |
