# Run the workshop locally

Read [doc/workshop-goal.md](doc/workshop-goal.md),
[doc/workshop.md](doc/workshop.md) and [AGENT_INTEGRATION.md](AGENT_INTEGRATION.md).
Install the target AEF runtime, run the local checks, and use the dashboard with
a completed session to inspect real retained evidence. The live entry point
requires its scoped preflight and an authenticated native model runtime.

Keep all assessment data in ignored engagement directories on a dedicated branch.
A completed memory review is not a completed Azure assessment.
